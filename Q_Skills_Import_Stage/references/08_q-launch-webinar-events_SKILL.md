# Q Launch, Webinar & Events

Use this skill for invitations, event pages, reminders, run-of-show drafts, FAQs, launch communications, and follow-up messages. Use Q's current approved brand guidance for tone and visual style. Event facts change quickly; check the current organiser brief and live registration page before publication.

## Confirm before publishing

Verify the event title, purpose, audience, organiser, date, start and end times, time zone, venue or platform, registration link, speakers and approved biographies, cost, capacity, accessibility arrangements, recording/photography consent, contact route, and cancellation/update plan. Include only details actually supplied or verified. If a detail is missing, omit it or mark it `[TO CONFIRM]`; never invent a link, agenda, speaker, accessibility provision, or recording policy.

The earlier pack listed a Q launch webinar on **1 November 2026, 09:00–12:00 UK time, on Microsoft Teams**, with a registration link in event materials. Treat those as previously supplied details, not proof that the event is still scheduled. Confirm them with the current organiser and registration materials before reuse. The original pack did not contain the registration URL.

## Write event copy

Use Q's warm, calm, inclusive, plain-English voice. Explain who the event is for, what attendees can expect, how to register, and what they need to join. Put date, time zone, platform/venue, and registration action where readers can find them quickly. Make calls to action clear and low pressure. Do not use false scarcity or promise outcomes, recordings, future events, or clinical support unless explicitly confirmed.

For reminders, foreground logistics and any preparation. For a cancellation or change, lead with what changed, then give the next step and a contact route. For follow-up, thank attendees without implying attendance or consent to future marketing.

## Accessibility and output

Use descriptive links, meaningful headings, readable mobile layouts, and alt text for informative images. State confirmed accommodations plainly; do not claim an event is accessible in every respect without evidence. Return the requested asset and a short checklist of unconfirmed facts. Keep placeholders visibly marked until an organiser confirms them.
